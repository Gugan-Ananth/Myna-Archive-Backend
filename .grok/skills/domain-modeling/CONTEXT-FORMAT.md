# CONTEXT.md format

Single-context repos keep one root `CONTEXT.md` with:

1. **One-line product summary**
2. **Glossary table** — Term | Definition | Avoid
3. **Core model** — canonical API/domain shapes
4. **Ubiquitous language rules**
5. **Bounded context notes**
6. **Open decisions** — filled by ADRs over time

When editing, prefer additive glossary rows. Remove terms only when the product drops the concept.
