# ADR format

```markdown
# NNNN. Title

Date: YYYY-MM-DD

## Status

Proposed | Accepted | Superseded by NNNN | Deprecated

## Context

Forces and constraints.

## Decision

What we chose.

## Consequences

Positive, negative, and impact on the frontend contract if any.
```

Number files as `docs/adr/NNNN-short-kebab-title.md`.
